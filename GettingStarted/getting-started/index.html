    Getting Started¶

    The supported path to a first Superluminal testnet trade is to use one of the tested reference-client bundles. Each bundle contains its client source, this generated documentation site, conformance vectors, and the same prefunding utilities.

    Choose a client¶

    • C++ reference client: build the terminal client from source.
    • Python reference client: install and run the terminal client.

    When reading this page on the hosted documentation site, download the current bundle and its manifest:

    • C++ reference client bundle
    • Python reference client bundle
    • Release manifest: source commit, version, build time, and SHA-256 checksums.

    Verify the downloaded file against manifest.json before unpacking it. If this page is inside an extracted bundle, use the enclosing reference client and its adjacent funding-tools/ directory; do not look for another download inside the bundle. Use conformance/test-vectors.json to verify signing and lossless unsigned 64-bit decoding.

    First testnet trade¶

    1. Download and verify one client bundle.
    2. Generate a new Solana-format Ed25519 keypair. Never use a bundled or shared key.
    3. Follow Funding accounts and wait for Funding complete..
    4. Follow the selected C++ or Python guide to connect the same wallet and subaccount 0.
    5. Wait for AccountSnapshot and synchronized market data.
    6. Submit a small, explicitly price-bounded LIMIT or IOC order using current symbology.
    7. Observe OrderAccepted or OrderReject and any fill settlement events.
    8. Cancel a working order, reconnect, and reconcile account state.

    The public gateway permits one authenticated WebSocket session per wallet. Run the funding utility before the trading client; a second authenticated session preempts the first.

    Build a custom client¶

    The bundles are the executable examples and signing implementations. Use the public API reference for the underlying HTTP, WebSocket, and wire contracts when building an independent integration.
